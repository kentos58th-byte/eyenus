# アイナス　created by KenMaP

**その人の人生の続きに、あなたのケアがある。**

ひとりの人の物語を読み、その人の目線でケアの場面を体験する学習アプリです。
ケアに関わるすべての人へ／1テーマ約10分・スマホだけで。

> その人を見るケアから、その人の目線に立つケアへ。その学びを、教える人がいなくても、誰でも、いつでも、楽しみながら。

## 公開URL
https://kentos58th-byte.github.io/eyenus/

## 学びの流れ
物語でその人の人生を知る → ベッドから見える景色と音で場面を体験する → 浮かんだ気持ちを振り返る → その人の心の声と比べる → 関わり方を変えた場面をもう一度体験する → 実際の場面のあとで振り返る

## 収録テーマ
- 在宅人工呼吸器ケア編（試作版）

## 使い方
- スマホのブラウザで公開URLを開き、「ホーム画面に追加」するとアプリとして使えます。
- 記録は端末のブラウザの中だけに保存されます（サーバーには送りません）。

## 監修・制作
KenMaP（集中ケア認定看護師）。看護・介護職の教育に用いることを想定しています。

## 構成
- `index.html` … アプリ本体
- `js/three.min.js` … 3D表示（three.js r128）
- `img/` … 物語（4コマ漫画）
- `manifest.webmanifest` / `sw.js` / `icons/` … ホーム画面追加・オフライン対応

## 注意
学習を補助するための教材です。実際のケアは、主治医の指示と事業所の手順を優先してください。
登場する人物・事例は架空のものです。
