# 患者目線の体験ライブラリ（KenMaP）

寝たきりで天井を見上げる患者さんの目線を、スマホのブラウザで体験する看護師向けの学習アプリです。
体験 → 浮かんだ言葉を残す → 患者さんの心の声と比べる → 自分の行動を決める → 関わり方を変えた場面を体験 → 臨床のあとで振り返る、という経験学習のサイクルで学びます。

> その人を見る看護から、その人の目線に立つ看護へ。その学びを、教える人がいなくても、誰でも、いつでも、楽しみながら。

## 収録テーマ
- 在宅人工呼吸器ケア編（試作版）

## 使い方
- スマホのブラウザで公開URLを開き、「ホーム画面に追加」するとアプリとして使えます。
- 記録は端末のブラウザの中だけに保存されます（サーバーには送りません）。

## 構成
- `index.html` … アプリ本体
- `js/three.min.js` … 3D表示（three.js r128）
- `img/` … 4コマ漫画
- `manifest.webmanifest` / `sw.js` / `icons/` … ホーム画面追加・オフライン対応

## 注意
学習を補助するための教材です。実際のケアは、主治医の指示と事業所の手順を優先してください。
登場する人物・事例は架空のものです。
