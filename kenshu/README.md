# KenMaP研修・学習会設計支援ツール（試作品）

研修づくりを「ねらい → デザイン → 本番 → ふりかえり」の道のりで進めるWebアプリです。

## 4つのステップ

| ステップ | できること |
| --- | --- |
| 1. ねらい | 研修名・対象・時間、三観と願い、目的と目標。「どんな感じの研修にしたい？」で指導法を複数選ぶ |
| 2. デザイン | **時間の流れ**：活動ごとに時間・指導法・進め方・使うもの・注意すること・担当を決める（選んだ指導法から下書きも作れる）<br>**使うツール**：投票・ワードクラウド・自由投稿・理解度チェック・自信度スケールから選び、使い方ガイドを見ながら、どの活動で使うかを決める<br>**アンケート**：意欲（ARCS）・目標ごとの達成感・気づきと疑問のセットと、自由な質問<br>**共有する**：設計を文章でコピー。読み込み用コードで、ほかの人の端末に設計をそのまま渡せる |
| 3. 本番 | 研修タイマーと「いまここ」の表示。活動ごとに設定したツールをワンタッチで開始。QRで受講者が参加 |
| 4. ふりかえり | アンケートとツールの結果はすぐ見られる。「分析と発問を依頼する」と、後日（1週間以内）KenMaPからフィードバックと問いかけが届く。問いに答え、「次回意識すること」を次の研修に引き継ぐ |

- 受講者用画面：`index.html?join=参加コード`（QRを読むと開く）
- 投影画面：`index.html?screen=参加コード`
- 運営の受付画面：`index.html?admin`（届いた依頼を見て、フィードバックと発問を書いて届ける）

## 2つのモード

- **デモモード**（`config.js` が空のとき）：1台のブラウザの中だけで動きます。本番画面の「デモ：受講者のスマホ画面」や、画面下の「運営の受付画面を見る（デモ）」で、一連の流れを確かめられます。
- **接続モード**（Supabase を設定したとき）：受講者それぞれのスマホから回答が集まり、依頼も運営に届きます。

## 複数人で使うための設定（はじめに1回だけ）

### 1. Supabase のプロジェクトを作る
1. https://supabase.com でアカウントを作り、「New project」でプロジェクトを作る（地域は Tokyo がおすすめ）
2. 左メニューの「SQL Editor」を開き、`schema.sql` の中身を全部貼り付けて「Run」
3. 続けて SQL Editor で、運営用の合言葉を1つ登録する（`好きな合言葉` は自分で決めた長めの文字に変える）
   ```sql
   insert into admin_keys(key) values ('好きな合言葉');
   ```

### 2. 接続情報を `config.js` に貼る
1. 「Project Settings」→「API」（または「Data API」）を開く
2. 「Project URL」と「anon public」のキーを、`config.js` の `supabaseUrl` と `supabaseAnonKey` に貼る

anon キーは公開しても大丈夫な鍵です（データベース側のルールで守っています）。「service_role」のキーは絶対に貼らないでください。

### 3. インターネットに公開する（GitHub Pages の例）
1. GitHub で新しいリポジトリを作り、`index.html` と `config.js` をアップロード
2. 「Settings」→「Pages」で、Branch を `main`、フォルダを `/ (root)` にして保存
3. 数分後に表示されるURLが講師用の画面です。運営の受付画面は、そのURLの最後に `?admin` をつけて開き、手順1-3の合言葉を入れます

## データと安全面

- 最初に開いたとき、データの使い方の説明が表示されます
- 受講者はログイン不要・無記名で参加します（端末ごとのランダムな番号だけを記録）
- 研修計画（三観・願いなど）は講師の端末にだけ保存され、「分析と発問を依頼する」を押したときだけKenMaPに届きます
- 依頼のデータは運営の合言葉がないと読めません。講師が自分の依頼の返事を見るには、講師の端末に保存された合言葉が必要です
- 研修の問いと受講者の回答は、参加コードを知っている人なら見られる設計です。個人情報や患者さん・利用者さんの情報は入力しないでください
- 別の端末で講師画面を開くと、研修計画や参加コードは引き継がれません（試作品の制限。設計は「読み込み用コード」で移せます）
